
# Library Activity Diagram

## About
This project describes the business process of reserving a physical book copy in the Library Reservation System.

## Purpose
The purpose is to model the use case **UC-01: Reserve a Book Copy** using an Activity Diagram.

## Process
The activity diagram describes the reservation process, including successful and unsuccessful outcomes, parallel activities, and notification messages.

## Scenarios
- SC-01: Successful reservation
- SC-02: No available book copies
- SC-03: Selected book copy is already reserved

## Project Structure
- `activity/` — Activity Diagram source and rendered image.
- `audit/` — consistency audit.
- `ai/` — AI usage log.
- `spec.md` — process specification.
- `DEFENSE.md` — project defense.
